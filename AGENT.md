# Focuslog UI Review Context

Product: one-page mobile web app for micro-progress logging.
Core loop: type -> tap send -. coin drops -> jar count increases.

Constraints:

- Minimal UI (no extra features)
- Mobile-first
- Next.js + Tailwind only
- No backend; localStorage only

What matters most:

- Reduce friction
- Clear hierarchy
- "Collecting" feeling without looking commercial
