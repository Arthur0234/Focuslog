Place these files in `/public` for proper PWA install icons:

- `/public/icon-192.png` (192x192)
- `/public/icon-512.png` (512x512)
- `/public/apple-touch-icon.png` (180x180)

Quick beginner path:
1. Prepare a square image (at least 512x512).
2. Use any icon generator (for example, "PWA icon generator") to export PNGs.
3. Save using the exact filenames above.

If these files are missing, install still works but icon quality may be poor or default.
